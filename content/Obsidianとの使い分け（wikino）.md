# wikino
- 全世界に knowledge を share する用
- Google検索にindexさせる用
  - ここがもしindexされないなら、[[しずかなインターネット]]同様、おれの利用はフェードアウトしていくことになるだろう
    - と思ったが、しずかなインターネットでおれの投稿記事はGoogle検索にindexされたようだ
    - その用途なら、[[Zenn Scraps]] や [[はてなブログ]] を使え（別の項目に書いた）
      - だがwikiフォーマットであることが重要なら、
        - 現状、wikinoが唯一の場所となるかもしれない
          - もし、ほかにfreeのwikiサービスがあり、それがGoogle検索にindexされるなら、そちらに引っ越しするかもしれない
            - GitHub wikiはまったくGoogle検索にindexされない。非常に有名なprojectであれば別だ
