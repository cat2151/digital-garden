    - contextとしてはQuartz4でのFlexsearchをgrepに無理やり置き換えた場合、を与えた
- grep のような全文走査検索に置き換えると、次の問題が発生します。
    - **サーバが必要になる**
        - grep は全ファイル走査が前提のため、検索 API や常駐サーバが必要になり、静的ホスティングができなくなります。
    * **クライアントサイドでは通信量が爆増する**
        * すべての記事（例：1000ページ分）をブラウザに取得して検索する必要があり、初回検索で数十 MB の通信が発生します。
    * **UX とパフォーマンスが著しく悪化する**
        * 検索が遅く、モバイル端末では実用的でなくなります。
