## coding agent
- おれは今、大部分のRust codingをcoding agentに任せている
  - メリット
    - Rustの急峻な学習曲線にブロッキングされることなく、成果物の恩恵を受けている（動くcodeを得られている）
      - [GitHub cat2151](https://cat2151.github.io/)
  - デメリット
    - coding agent全般のデメリットと同じ
      - そのプログラミング言語をさわる上で重要なアーキテクチャ理解などのスキルの経験値をあまり得られていない
        - 例えばドラクエで、はぐれメタルがトヘロスやニフラムで経験値を得られないような環境だったとして、
          - そこでトヘロスやニフラムを使っているような状態
